# My Closet Stylist — iPhone

## Publicarla
1. Crea un repositorio en GitHub.
2. Sube todos los archivos de esta carpeta.
3. En Render crea un Web Service conectado a ese repositorio.
4. Build command: `npm install`
5. Start command: `npm start`
6. Agrega `OPENAI_API_KEY` como variable de entorno.
7. Publica. Render te dará una URL `https://...onrender.com`.

## Instalarla en iPhone
1. Abre esa URL en Safari.
2. Toca Compartir.
3. Toca “Agregar a pantalla de inicio”.
4. Toca “Agregar”.

El clóset y el historial se guardan localmente en el iPhone usando IndexedDB.
Si borras los datos del sitio/Safari, el clóset local puede perderse.
